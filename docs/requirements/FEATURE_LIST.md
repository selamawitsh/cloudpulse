# CloudPulse Feature List

## Essential (version 1, MVP)

| Feature | Why it is essential |
|---|---|
| Register and sign in | Every user needs an account |
| Add, edit, pause, delete monitors | Core purpose |
| Automatic HTTP checks | Core purpose |
| Response-time and status recording | Needed for history and uptime |
| Uptime calculation | Main number users care about |
| Incident creation and resolution | Turns failures into useful records |
| Email notification | Users must be told about outages |
| Dashboard | Users need to see results |

## Important (version 1 if time allows)

- Webhook notifications
- Public status page
- Response-time charts
- Incident history page

## Advanced (later, not version 1)

- Check from multiple regions
- Keyword or content checks
- SSL certificate expiry alerts
- Team accounts and shared monitors
- Slack or Telegram notifications
- Maintenance windows

## Out of scope (we will NOT build)

- Automatic fixing of outages
- Mobile app
- Many microservices
- Kubernetes
