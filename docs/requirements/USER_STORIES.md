# CloudPulse User Stories

## Accounts
- US-01: As a visitor, I want to register with my email and
  password, so that I can have my own account.
- US-02: As a user, I want to sign in and out, so that my data
  stays private.

## Monitors
- US-03: As a website owner, I want to add my website to
  CloudPulse, so that it is checked automatically.
- US-04: As a user, I want to pause a monitor, so that I do not
  get alerts during planned maintenance.
- US-05: As a user, I want to delete a monitor, so that I can
  stop monitoring services I no longer use.

## Results
- US-06: As a backend developer, I want to see response-time
  charts, so that I can notice my API getting slower.
- US-07: As a DevOps engineer, I want to see uptime percentage,
  so that I can measure availability.

## Incidents
- US-08: As a DevOps engineer, I want an incident created when a
  service fails, so that I have a record of what happened.
- US-09: As a user, I want to see past incidents, so that I can
  review how often problems occur.

## Notifications
- US-10: As a website owner, I want an email when my site goes
  down, so that I know before my customers do.
- US-11: As a user, I want an email when my site recovers, so
  that I know the problem is over.

## Status page
- US-12: As a website owner, I want a public status page, so that
  my customers can see whether my service is healthy.
