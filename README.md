# CloudPulse

A website and API uptime monitoring platform. It checks services
automatically, records uptime history, detects failures, creates
incidents and sends notifications.

Think of CloudPulse as a digital health checker for websites and APIs.

## Status

Phase 3: User journeys and workflows (in progress)

## Technology stack

| Area | Technology |
|---|---|
| Frontend | Next.js |
| Backend | Java, Spring Boot |
| Database | PostgreSQL |
| Background jobs and caching | Redis |
| Containers | Docker, Docker Compose |
| Version control | Git, GitHub |
| CI/CD | GitHub Actions, GitHub Container Registry |
| Reverse proxy | Nginx |
| Cloud | AWS |
